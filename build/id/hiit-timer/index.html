HIIT – Loopy Timer

Contoh rencana HIIT sederhana: 40 detik latihan dan 20 detik istirahat, 10 ronde per set, 2 set dengan jeda 1 menit di antaranya. Sesuaikan waktunya dengan levelmu.

Tentang Loopy Timer

Loopy Timer adalah timer interval gratis untuk Tabata, HIIT, EMOM, Pomodoro, dan siklus buatanmu sendiri. Jalankan beberapa timer sekaligus langsung di browser. Tanpa pendaftaran, tanpa instalasi.

  • Beberapa timer berjalan bersamaan, masing-masing dengan siklus latihan / istirahat sendiri
  • Preset Tabata, HIIT, EMOM, dan Pomodoro, atau buat sendiri
  • Penanda suara, timer tersimpan, dan bisa dipakai offline sebagai aplikasi web yang dapat dipasang
  • Bagikan latihan atau sesi fokusmu sebagai teks atau gambar

Pertanyaan umum

Apakah Loopy Timer gratis?

Ya. Gratis, tidak perlu akun, dan berjalan di browser.

Bisakah saya menjalankan lebih dari satu timer sekaligus?

Bisa. Tambahkan timer sebanyak yang kamu mau dan mulai masing-masing secara terpisah, misalnya satu set Tabata dan satu sesi Pomodoro berdampingan.

Apakah timer saya tersimpan?

Timer disimpan di browser dan tetap ada setelah halaman dimuat ulang. Timer kamu tidak pernah diunggah. Kamu juga bisa menambahkan aplikasi ke layar utama dan memakainya offline.
