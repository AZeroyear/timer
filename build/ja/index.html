Loopy Timer

タバタ、HIIT、EMOM、ポモドーロに使える無料のオンラインインターバルタイマー。複数のタイマーを同時に実行でき、ワーク / 休憩のサイクルを自由に作成し、結果をシェアできます。登録不要。

Loopy Timer について

Loopy Timer は、タバタ、HIIT、EMOM、ポモドーロ、そして自作のサイクルに使える無料のインターバルタイマーです。複数のタイマーを同時に動かせます。ブラウザだけで使え、登録もインストールも不要です。

  • 複数のタイマーを同時に実行。それぞれに独自のワーク / 休憩サイクルを設定できます
  • タバタ・HIIT・EMOM・ポモドーロのプリセット付き。自分でも作れます
  • 音で通知、タイマーを自動保存、インストールしてオフラインでも使えます
  • 完了したトレーニングや集中セッションをテキストや画像でシェアできます

よくある質問

Loopy Timer は無料ですか？

はい。無料で、アカウント登録も不要です。ブラウザ上で動きます。

複数のタイマーを同時に動かせますか？

はい。好きな数だけタイマーを追加して、それぞれ独立して開始できます。たとえばタバタとポモドーロを並べて使えます。

タイマーは保存されますか？

タイマーはブラウザに保存されるので、リロードしても残ります。タイマーの内容がアップロードされることはありません。ホーム画面に追加すればオフラインでも使えます。
