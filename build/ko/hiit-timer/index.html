HIIT – Loopy Timer

간단한 HIIT 예시입니다. 40초 운동과 20초 휴식을 10라운드씩 1세트로 하고, 사이에 1분 휴식을 두고 2세트를 합니다. 시간은 자신의 수준에 맞게 조절하세요.

Loopy Timer 소개

Loopy Timer는 타바타, HIIT, EMOM, 포모도로, 그리고 직접 만든 사이클에 쓸 수 있는 무료 인터벌 타이머입니다. 여러 타이머를 동시에 실행할 수 있고, 브라우저에서 바로 사용하며 가입도 설치도 필요 없습니다.

  • 여러 타이머를 동시에 실행, 각각 별도의 운동 / 휴식 사이클 설정
  • 타바타, HIIT, EMOM, 포모도로 프리셋 제공, 직접 만들 수도 있음
  • 소리 알림, 타이머 자동 저장, 웹 앱으로 설치해 오프라인에서도 사용
  • 끝낸 운동이나 집중 세션을 텍스트나 이미지로 공유

자주 묻는 질문

Loopy Timer는 무료인가요?

네. 무료이며 계정이 필요 없고 브라우저에서 실행됩니다.

타이머를 동시에 여러 개 실행할 수 있나요?

네. 원하는 만큼 타이머를 추가해 각각 따로 시작할 수 있습니다. 예를 들어 타바타와 포모도로를 나란히 실행할 수 있습니다.

타이머가 저장되나요?

타이머는 브라우저에 저장되어 새로고침해도 남아 있으며, 타이머 내용은 업로드되지 않습니다. 홈 화면에 추가하면 오프라인에서도 사용할 수 있습니다.
